# Production LLM Engineering

This repository is a collection of my **Jupyter Notebook learning work in LLM and Agentic AI engineering**.

I am using these notebooks to build a strong understanding of how modern AI systems work — starting from the fundamentals of Transformers and LLMs, and gradually moving toward fine-tuning, RAG, multimodal AI, agents, and production-level AI systems.

The main purpose of this repository is to **learn concepts by studying them, understanding how they work internally, and documenting my learning through Jupyter Notebooks**. Each notebook focuses on a specific concept so that I can easily revisit, understand, and build upon it later.

The learning journey covers the complete path from **LLM fundamentals to production-oriented AI engineering**, including model architectures, inference, fine-tuning, retrieval systems, agentic workflows, context management, evaluation, and LLMOps.

This repository will continue to evolve as I learn new concepts, explore different approaches, and expand my understanding of modern LLM systems.

## Goal

The goal is to maintain a **clear and organized record of my LLM engineering learning journey**, while building the knowledge required to understand and eventually develop production-grade LLM and Agentic AI systems.
